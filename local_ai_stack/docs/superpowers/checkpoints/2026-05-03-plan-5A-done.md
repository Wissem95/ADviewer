## Bug critique corrigé en Task 14

`Stage.run` n'enregistrait pas le `StageResult` dans
`ctx.stage_results[name]` ; les stages avals (Stage3 lit `intake`, Stage5
lit `plan`/`ground`, Stage7 lit `execute`) ne voyaient rien et
`Pipeline.files_modified` restait vide. Détecté lors du test E2E,
corrigé dans `backend/pipeline/base.py` avec aussi l'accumulation
`ctx.total_cost_usd / total_tokens_in/out`.
